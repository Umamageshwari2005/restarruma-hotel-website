📝 Project Description

This project is a static restaurant website that showcases the restaurant's menu, location, and contact details. It features a visually appealing design with a responsive layout.

✨ Features

🍽️ Beautiful Restaurant Homepage

📜 Menu Page with Food Items & Prices

📍 Location & Contact Section

📱 Fully Responsive Design

🎨 Modern UI with CSS Styling

📂 Technologies Used

HTML5

CSS3 (Including Flexbox & Grid)
